# Artifact, library, game, and simulation profile

MUST define users, inputs/outputs, format, compatibility, and acceptance for the actual delivered artifact. Inspect rendered/opened output, links, and representative content for documents/static output. Libraries need public-contract and consumer checks.

Games/simulations/interactive tools MUST inspect rendering/primary interaction, repeated cleanup, cancellation, input modes, resource ownership and numerical/domain invariants as applicable. Syntax checks do not establish usable interaction or model validity.

MUST identify exact bytes or source/build/configuration and recovery to a prior artifact. A simple local artifact needs no server, database, login, or monitoring service; an appropriate delivery check and named owner suffice. Select other profiles/modules for their risks.
