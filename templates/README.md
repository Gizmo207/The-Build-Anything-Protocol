# Adoption templates

Merge [AGENTS.md](AGENTS.md) into existing instructions. Record each bounded change; low-risk work may use concise prose as allowed by [the core](../CORE.md). Fill [protocol-record.json](protocol-record.json) when using machine validation or when the project requires it. Placeholders intentionally fail readiness.

Use [checkpoint.md](checkpoint.md) at phase transitions and [pull_request_template.md](pull_request_template.md) for handoff. Small changes can use one record with links to approved artifacts. See [checker documentation](../tools/README.md).
